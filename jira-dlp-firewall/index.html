🎯 Overview

Enterprise DLP firewall for Jira Cloud: scans descriptions, comments and attachments for API keys, PII, and credentials in real-time with zero external egress. 100% Forge hosted.

🌟 Key Capabilities

100+ Secret & PII Vector Scanners

Real-time detection of AWS keys, OpenAI tokens, private keys, database connection strings, JWT tokens, and PII.

1-Click Neutralize & Redact

Redact compromised secrets in comments and descriptions in 1 click without losing surrounding text formatting.

Workflow Security Gate

Blocks tickets from transitioning to Done or Public if unredacted high-risk credentials remain in ticket history.

Hash-Linked Audit Ledger

SHA-256-linked audit records support review of app activity. They do not by themselves prove SOC 2 compliance or certify a tenant's data handling.

  • Step 1: Request private pilot access via pilot@neural-void.com to receive the installation link and tenant setup guide.

🔒 Zero-Egress Security & Architecture

IntraGuard Jira DLP & Secret Firewall is built 100% on the native Atlassian Forge serverless infrastructure:

  • No External Servers: All compute runs inside isolated Atlassian Forge microVMs.
  • Data Boundary: The app is designed to use Atlassian Forge runtime and storage rather than external application servers; customers should verify its configuration for their tenant.
  • Compliance Assessment: Customers remain responsible for their GDPR, SOC 2, and data-residency assessments. Neural Void makes no independent certification claim.
