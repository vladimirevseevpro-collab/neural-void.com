Smart Defaults & Definition of Done Guard

Enforce DoD Checklists, Auto-Populate Description Templates and Block Incomplete Done Transitions

Join Public Beta ⚡

🎯 Overview

Automate Jira quality gates: enforce Definition of Done checklists on issue view, pre-populate description templates, and block premature Done transitions. 100% Forge zero-egress.

🌟 Key Capabilities

Interactive DoD Checklists

Dynamic checklist widget on issue view tracking Definition of Done completion in real-time with interactive progress badges.

Smart Description Templates

Automatically populates standard reproduction steps, acceptance criteria, and components upon issue creation per issue type.

Workflow Transition Guard

Built-in workflow validator that intercepts and blocks transitions to 'Done' until 100% of required checklist items are checked.

Per-Issue-Type Rules

Configure custom templates, mandatory checklists, and automated defaults per Project and Issue Type in project settings.

🚀 Quick Start Guide

  • Step 1: Request public beta access via pilot@neural-void.com to enable the Forge app for your Jira Cloud instance.
  • Step 2: Navigate to Project Settings -> Smart Defaults & DoD Configuration.
  • Step 3: Define your Default Description Templates and required DoD Checklist items for Bugs, Stories, and Tasks.
  • Step 4: Open any Jira issue to see the live checklist widget and test the transition validator.

🔒 Zero-Egress Security & Architecture

Smart Defaults & Definition of Done Guard is built 100% on the native Atlassian Forge serverless infrastructure:

  • No External Servers: All compute runs inside isolated Atlassian Forge microVMs.
  • Data Boundary: The app is designed to use Atlassian Forge runtime and storage rather than external application servers; customers should verify its configuration for their tenant.
  • Compliance Assessment: Customers remain responsible for their GDPR, SOC 2, and data-residency assessments. Neural Void makes no independent certification claim.
