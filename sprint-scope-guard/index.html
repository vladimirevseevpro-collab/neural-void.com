Core Pillars

Engineered for High-Discipline Scrum Teams

Review the scope that matters now: an active sprint or a planned sprint in the backlog.

Scope boundary: no closed-sprint history, sprint-failure forecast, what-if velocity simulator, or AI root-cause analysis.

📡 Current and Planned Sprint Audit

Open the active Scrum sprint or a planned sprint in the backlog. The dashboard uses Jira issue and changelog data from the project being viewed; when relevant data is absent, it shows an empty state.

⚖️ Authorized Scope Swap

Select an injected issue and one or more baseline issues. With the Jira permissions required for the action, Scope Swap records the injected issue's approval and moves the selected baseline issues back to the backlog. The app does not choose issues or act automatically.

📊 Remaining Baseline

Separate the remaining members that were in the sprint at its start from later additions and recorded removals. The baseline denominator excludes work that has since left the sprint; it is not an original-commitment snapshot.

📝 Current-Sprint Summary and Exports

Review baseline, injected, and removed/descheduled lists with Jira-derived audit details, then export the displayed current-sprint data as CSV, JSON, or Markdown. The summary does not use AI or assign root causes.

⚡ Custom Agile JQL Functions

Query scope deviations natively in Jira filters and dashboards:

issue in addedToSprintAfterStart()
issue in removedFromSprint()
issue in hasUnresolvedSubtasks()

🔗 Optional Manual Webhook Test

In the reviewed remediation source, a project administrator may manually test a supported Slack or Microsoft Teams webhook. The test sends only generic static text and a timestamp; it sends no automatic alerts. Forge egress is allowlisted to hooks.slack.com and *.webhook.office.com.

Kernfunktionen

Entwickelt für disziplinierte Scrum-Teams

Prüfen Sie den Umfang, der jetzt zählt: einen aktiven Sprint oder einen geplanten Sprint im Backlog.

Funktionsgrenze: keine Historie abgeschlossener Sprints, keine Prognose eines Sprint-Fehlschlags, kein Was-wäre-wenn-Geschwindigkeitssimulator und keine KI-Ursachenanalyse.

📡 Prüfung aktiver und geplanter Sprints

Öffnen Sie den aktiven Scrum-Sprint oder einen geplanten Sprint im Backlog. Das Dashboard verwendet Jira-Issue- und Changelog-Daten des angezeigten Projekts und zeigt bei fehlenden Daten einen leeren Zustand.

⚖️ Autorisierter Scope Swap

Wählen Sie ein hinzugefügtes Issue und ein oder mehrere Baseline-Issues. Mit den dafür erforderlichen Jira-Berechtigungen dokumentiert Scope Swap die Genehmigung des hinzugefügten Issues und verschiebt die gewählten Baseline-Issues zurück ins Backlog. Die App wählt keine Issues und handelt nicht automatisch.

📊 Verbleibende Baseline

Trennt die noch im Sprint vorhandenen Mitglieder vom Sprintstart von späteren Ergänzungen und erfassten Entfernungen. Der Baseline-Nenner schließt Arbeit aus, die den Sprint verlassen hat; er ist keine gespeicherte Ursprungszusage.

📝 Aktuelle Sprint-Zusammenfassung und Exporte

Prüfen Sie Baseline-, hinzugefügte und entfernte/ausgeplante Aufgaben mit Jira-basierten Auditdetails und exportieren Sie die angezeigten Daten als CSV, JSON oder Markdown. Die Zusammenfassung nutzt keine KI und weist keine Ursachen zu.

⚡ Eigene Agile JQL-Funktionen

Filtern Sie Sprint-Abweichungen direkt in Jira-Boards und Berichten:

issue in addedToSprintAfterStart()
issue in removedFromSprint()
issue in hasUnresolvedSubtasks()

Der Test sendet nur einen generischen statischen Text und einen Zeitstempel, keine automatischen Warnungen. Forge-Egress ist auf hooks.slack.com und *.webhook.office.com beschränkt.

Ключевые возможности

Инструмент дисциплины для Scrum-команд

Проверяйте объём, который важен сейчас: активный спринт или запланированный спринт в бэклоге.

Граница функций: нет истории закрытых спринтов, прогноза срыва спринта, симулятора скорости «что если» и ИИ-анализа первопричин.

📡 Проверка активного и запланированного спринта

Откройте активный Scrum-спринт или запланированный спринт в бэклоге. Панель использует данные задач и changelog Jira выбранного проекта и показывает пустое состояние, когда данных нет.

⚖️ Авторизованный Scope Swap

Выберите добавленную задачу и одну или несколько базовых задач. При наличии разрешений Jira для действия Scope Swap фиксирует одобрение добавленной задачи и переносит выбранные базовые задачи обратно в бэклог. Приложение не выбирает задачи и не действует автоматически.

📊 Оставшийся базовый объём

Отделяет оставшиеся задачи, присутствовавшие в спринте на старте, от поздних добавлений и зафиксированных удалений. В знаменатель базового объёма не входит работа, которая уже вышла из спринта; это не сохранённый исходный коммитмент.

📝 Сводка текущего спринта и экспорт

Проверяйте списки базового объёма, добавленных и удалённых/перенесённых задач с деталями аудита Jira и экспортируйте показанные данные в CSV, JSON или Markdown. Сводка не использует ИИ и не назначает причины изменений.

⚡ Кастомные Agile JQL-функции

Ищите отклонения скоупа напрямую через стандартный поиск Jira:

issue in addedToSprintAfterStart()
issue in removedFromSprint()
issue in hasUnresolvedSubtasks()

Тест отправляет только общий статический текст и метку времени, без автоматических оповещений. Egress Forge ограничен allowlist: hooks.slack.com и *.webhook.office.com.
